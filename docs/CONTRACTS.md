# Private contract distribution

Protocol source of truth is `llm.thrift` in the private inference-service repository. Compiler/runtime are Apache Thrift 0.25.0; protocol fields and methods remain unchanged during extraction. This backend consumes the normal wheel `local-llm-contract==1.0.0`, never inference implementation packages, editable paths, a sibling checkout or service main.

The exact release wheel SHA256 is `620efac1f6f81475e71e4a5d22c06090c6a4c028ed2a46bc1554ffb1a9c41d2f`. It was generated from inference source commit `30fbcecb5b5a071e33afe0b268c75dd3da6192c7` and published as a private GitHub Release asset. The artifact-only distribution commit is `7a51e2717085d774c55696a1fb8d050bec7c62b0`, tagged `contracts-v1.0.0`; its tree contains only wheel, checksum and provenance. The backend lock pins this commit and hash. The mutable branch is not an install input.

Local bootstrap may use authenticated GitHub Release download. CI uses a dedicated read-only inference-service deploy key held as `CONTRACTS_DEPLOY_KEY` in backend Actions secrets. The fetch script uses an ephemeral **bare** Git object store to retrieve the pinned artifact commit and extracts only the wheel blob, with no service source checkout/build. SSH host public keys come from GitHub's HTTPS metadata endpoint; strict host key verification is enabled. The wheel hash must match before installation. The existing user's OAuth login credentials were not copied into repositories or CI secrets.

The independent [private access workflow](https://github.com/GodfreyLyu/review-backend/actions/runs/41948572032) passed, including authenticated cross-repository download, hash verification and actual wheel installation. Rotate the key by adding a new read-only deploy key on inference-service and replacing the backend secret. Removal fails closed; repositories must stay private. Developers need their own access or a separately provisioned read-only key.

For an upgrade, publish a new immutable version/tag/artifact first; review the generated diff and compatibility report in inference-service; update all version/hash/commit fields in this backend together, rerun private-access and backend suites, and release independently of the service image. Never overwrite an existing version's release wheel. Review Kafka envelopes and execution-version changes are owned here, not in generic Thrift.

The client pins instance ID across start/get/cancel, records intent before sending, and never resends start after a lost reply. Socket timeouts do not prove cancellation. Terminal result TTL can make an old request unknowable; such cases retain the slot in explicit recovery until operator evidence establishes safety. See the inference-service contract README for field IDs, optional-field compatibility, error codes and retention guarantees.
